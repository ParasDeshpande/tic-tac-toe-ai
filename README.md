# Tic-Tac-Toe AI

An unbeatable Tic-Tac-Toe game with AI opponent using the Minimax algorithm.

## Features
- Play against an unbeatable AI
- Clean command-line interface
- Minimax algorithm implementation

## Installation
```bash
pip install -r requirements.txt
```

## Usage
```bash
python main.py
```

## Project Structure
- `game/board.py` - Board management
- `game/game_engine.py` - Game logic
- `ai/minimax.py` - AI implementation
- `main.py` - Entry point

## How to Play
Enter numbers 0-8 to place your mark (X). AI plays as O.
